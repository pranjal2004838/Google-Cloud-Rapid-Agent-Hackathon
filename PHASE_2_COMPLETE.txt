================================================================================
                          RECOMMENDED TECH STACK
================================================================================

Frontend:
├─ HTML5 + Tailwind CSS (CDN)
├─ Vanilla JavaScript (no build step)
└─ Single index.html with client-side routing

Backend:
├─ FastAPI (Python)
├─ MongoDB (database)
├─ JWT + bcrypt (authentication)
└─ Gemini on Vertex AI (AI extraction)

Authentication:
├─ JWT tokens (24-hour clinic, 30-day patient)
├─ bcrypt password hashing (10 rounds)
├─ 6-digit OTP (5-minute expiry)
└─ Rate limiting (3 requests per 15 min)

Deployment:
├─ Google Cloud Run (backend)
├─ Cloud Storage (documents)
├─ MongoDB Atlas (database)
└─ Vertex AI (Gemini)

================================================================================
                          SECURITY CHECKLIST
================================================================================

Authentication:
├─ Passwords hashed with bcrypt (min 10 rounds)
├─ OTP: 6-digit, 5-minute expiry
├─ OTP rate limiting: Max 3 requests per 15 min
├─ JWT tokens: 24-hour (clinic), 30-day (patient)
└─ Refresh token mechanism

Authorization:
├─ Patient must authorize clinic access via OTP
├─ Clinic cannot access unauthorized patient data
├─ Audit log all access attempts
└─ Session management

Data Protection:
├─ HTTPS only for all API calls
├─ Encrypt sensitive fields at rest
├─ No sensitive data in logs
└─ Remove debug OTP from production
