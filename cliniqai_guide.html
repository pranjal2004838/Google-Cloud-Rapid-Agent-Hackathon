What is CliniqAI?

Imagine a smart assistant for small clinics that can read handwritten prescriptions, remember every patient's history, and instantly warn doctors about dangerous drug combinations. That's CliniqAI—built on Google's most advanced AI technology.

The Real Problem

📋 How Clinics Work Today

In small clinics across India (and the world), patient records are:

  • Written on paper in a register
  • Sent via WhatsApp photos
  • Scattered across different clinics
  • Lost or forgotten after 6 months

The Real Consequences:

  • Medicines get prescribed twice (wasteful & expensive)
  • Drug allergies are ignored (dangerous!)
  • Tests get repeated (more money wasted)
  • Doctors have no history to make informed decisions

✨ How CliniqAI Fixes It

CliniqAI is a smart agent that:

  • 📸 Reads photos of prescriptions (even handwritten, in Hindi or English)
  • 🧠 Understands patient names, medicines, allergies, and test results
  • 💾 Stores everything in a searchable database
  • 🔍 Lets doctors search in plain English: "Show me all patients on metformin"
  • ⚠️ Automatically warns about dangerous drug combinations BEFORE the doctor prescribes

🎯 The "Wow" Moment

A patient visits with a penicillin allergy from 2 years ago. The doctor prescribes amoxicillin (a similar drug). CliniqAI instantly alerts: "DANGER! This patient is allergic to penicillin. Amoxicillin belongs to the same family. This could cause a severe reaction!" The doctor stops and prescribes something safe instead. Patient is protected.

How CliniqAI Works (Step by Step)

📸 Doctor Takes a Photo

A doctor or clinic assistant takes a photo of a prescription, lab report, or discharge summary using their phone or computer. It could be handwritten in Hindi, English, or even a mix.

📤 Upload to the Website

The photo is uploaded through a clean, simple web interface. The system immediately saves it to a secure vault (Google Cloud Storage) for proof and audit trail.

🤖 AI Reads the Document

Google's advanced AI (Gemini) reads the photo and extracts important information:

  • Patient name and age
  • Medicines prescribed with dosages
  • Duration of treatment
  • Known allergies
  • Test results and recommendations

⚠️ Safety Check Runs

Before saving, the system checks for dangerous combinations:

  • Is the new medicine safe for this patient's allergies?
  • Does it conflict with medicines they're already taking?
  • Are there any known dangerous interactions?

If danger found: Alert the doctor immediately with a clear explanation!

💾 Save to Database

Clean, structured data is saved to MongoDB (a smart database). The patient's complete history is now searchable and available to any doctor at any clinic.

📊 Doctor Sees Results

The doctor sees a beautiful summary with:

  • ✅ Extracted patient information
  • ⚠️ Any safety warnings (in RED if dangerous!)
  • 🔗 Link to the original prescription photo
  • 📋 Patient's complete history from all previous visits

The Technology Stack (Explained for Beginners)

Every tool we use has a specific job. Here's what each does and why we chose it:

🤖 Gemini AI

What it is: Google's super-smart AI that can understand images, text, and even handwriting.

What it does: Reads prescription photos and extracts patient information automatically.

Why Google? Best at reading handwritten text in multiple languages (Hindi, English, etc.)

What it is: A secure vault on the internet for files.

Why? If there's ever a question about what was prescribed, we have the original photo.

🚀 Cloud Run

What it is: A server that runs our application on the internet.

What it does: Hosts the backend and makes the app available 24/7.

Confusing Terms Explained (For Your Friends)

1️⃣ What is an "Agent"?

An agent is like a smart assistant that can think and make decisions. Instead of following a fixed script, it can:

  • Understand what you ask
  • Decide what tools to use
  • Use those tools to solve the problem
  • Report back with an answer

Real Example: When you ask "Find all patients allergic to penicillin", the agent thinks: "I need to search the database" → opens MongoDB → searches → brings back results. That's what an agent does!

2️⃣ Gemini vs. Vertex AI vs. "Gemini on Vertex AI" (What's the Difference?)

Gemini = The Brain

  • Gemini is Google's AI model (the actual smart brain)
  • It's like a super-intelligent person who can read and understand things
  • You can access Gemini through different platforms

Vertex AI = The Professional Studio

  • Vertex AI is Google Cloud's AI platform (like a control center)
  • It's where you manage, monitor, and run AI models securely
  • It's like a professional studio where you can use Gemini

Gemini on Vertex AI = Using Gemini Through Google's Professional Platform

  • This means: Use the Gemini brain, but through the Vertex AI platform
  • Why? Better security, monitoring, and integration with other Google tools

Simple Analogy:

  • Gemini = A brilliant doctor
  • Vertex AI = A professional hospital
  • Gemini on Vertex AI = That brilliant doctor working in the professional hospital
3️⃣ What is "ADK" (Agent Development Kit)?

ADK is Google's toolkit for building smart agents. It's like a LEGO set for building intelligent assistants.

What does it do?

  • Lets you define "tools" that an AI can use (like a toolbox)
  • Lets the AI decide which tool to use for each task
  • Handles the communication between the AI and the tools

Real Example in CliniqAI: We give the agent these tools:

  • 🔧 Tool 1: "Read a photo using Gemini"
  • 🔧 Tool 2: "Check for drug conflicts"
  • 🔧 Tool 3: "Save data to MongoDB"
  • 🔧 Tool 4: "Search MongoDB for patient history"

When a doctor uploads a prescription, the agent thinks: "First read the photo → Then check for conflicts → Then save the data → Finally show results"

Why ADK? Instead of writing complex code to connect everything, ADK handles it automatically.

4️⃣ What is "MongoDB"? (And Why Do We Use It?)

MongoDB is a database (a place to store information). Think of it like a smart filing cabinet that can organize and find information super fast.

Traditional Database (like Excel):

  • You need to define columns first: Name | Age | Medicine | Allergy
  • Every patient record must have the same columns
  • If a patient has 5 medicines but another has 2, it's awkward
  • Rigid and inflexible

MongoDB (Flexible):

  • Each patient record can be different
  • Patient A can have 5 medicines, Patient B can have 2
  • You can add new fields anytime (like "test results", "doctor notes")
  • Flexible and easy to search

Real Example:

Patient 1: { name: "Ramesh Gupta", age: 45, medicines: ["Metformin", "Aspirin"], allergies: ["Penicillin"], lastVisit: "2024-05-20" } Patient 2: { name: "Priya Sharma", age: 32, medicines: ["Paracetamol"], allergies: ["Sulfa", "Ibuprofen"], lastVisit: "2024-05-19", testResults: ["Blood Test", "Urine Test"] }

Why MongoDB for CliniqAI?

  • ✅ Medical records are messy and varied
  • ✅ Different patients have different data
  • ✅ We can search fast: "Find all patients on Metformin"
  • ✅ We can add new fields without breaking anything
  • ✅ Free tier available (512MB)
5️⃣ What is "Allergy Family"?

Medicines are grouped into families based on chemical similarity. If you're allergic to one, you might be allergic to others in the same family.

Example:

  • Penicillin Family: Penicillin, Amoxicillin, Ampicillin, Augmentin
  • Cephalosporin Family: Cefalexin, Cefuroxime, Ceftriaxone

If a patient is allergic to Penicillin, they're probably allergic to all medicines in the Penicillin family. CliniqAI checks this automatically!
